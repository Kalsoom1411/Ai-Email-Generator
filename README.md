
# ✉️ AI Email Generator

An AI-powered web application that generates professional emails using Groq and Gradio.

## 🚀 Features

- Generate professional emails using AI
- Multiple email types
- Multiple tones
- Short, medium and detailed emails
- English, Urdu and Roman Urdu support
- AI-generated subject lines
- Clear/reset button
- Error handling
- Simple and user-friendly Gradio interface

## 🛠️ Tech Stack

- Python
- Google Colab
- Groq API
- Gradio
- GitHub

## 🤖 AI Model

OpenAI GPT-OSS-120B through Groq API.

## 🔐 API Security

The Groq API key is stored using Google Colab Secrets.

Secret name:

GROQ_API_KEY

The API key is not hard-coded into the application.

## ▶️ How to Run

1. Open the project notebook in Google Colab.
2. Add your Groq API key to Colab Secrets.
3. Create a secret named:

GROQ_API_KEY

4. Install the required packages.
5. Run the application.
6. Open the Gradio public URL.

## 📌 Deployment

The application is deployed temporarily through Gradio's public sharing feature while running in Google Colab.

The public demo depends on the active Google Colab session.
